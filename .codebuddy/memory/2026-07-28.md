# 2026-07-28

## 修复港股数据获取问题

用户添加港股代码 07709 后无法获取行情数据。根因：`server/scheduler.js` 中：

1. `REGION_TZ` 和 `isMarketOpen` 使用 `'A股'`/`'港股'`/`'美股'` 中文 key，但 data/holdings.json 中实际存的是 `hk`/`sh`/`sz`/`us`，导致时区查不到、交易时段判断失效。
2. `fetchPrices(active.map(h => h.code))` 传递裸代码（如 `07709`），但腾讯行情接口要求前缀格式（`hk07709`）。

修复：REGION_TZ key 改为 hk/sh/sz/us；isMarketOpen 条件对应调整；fetchPrices 传参改为 `h.region + h.code`，查找也同步使用 prefixed key。

## 新增：日涨跌告警功能

用户需求：设置单日跌幅/涨幅超过阈值时飞书机器人提醒。

### 改动范围

**server/server.js** — createHolding 增加 dailyDropAlertPct / dailyRiseAlertPct 字段；新增 PATCH /api/holdings/:id 路由用于更新持仓级字段（含日涨跌告警阈值）。

**server/scheduler.js** — runOnce 循环中，更新价格后、策略评估前，检查今日涨跌幅是否超出告警阈值，触发则调用 sendCard 推送飞书卡片（DAILY_RISE / DAILY_DROP 类型），并用 dailyAlertSentDate 做同一日去重。

**server/notifier.js** — buildCard 增加 DAILY_RISE/DAILY_DROP 卡片模板（标题红色/黄色，含品种/代码/市场/当前价/详情）。

**前端** — useHoldings 增加 updateHolding 方法；AddHoldingModal 增加日跌/日涨告警输入框；HoldingCard 指标网格增至7列，新增日跌告警/日涨告警单元格，行内可点编辑按钮修改并自动保存。

## 新增：场外基金净值数据支持

用户发现持仓中的基金（005827/163406）在腾讯行情接口查不到，显示"无行情"。原因是场外基金不在股票交易所挂牌，腾讯 qt.gtimg.cn 不支持。

新增 `server/provider/fund.js` — 对接东方财富基金净值 API（https://api.fund.eastmoney.com/f10/lsjz），返回最新净值和前日净值。

修改 `server/scheduler.js` — runOnce 中按类型分流：`type` 包含"基金"的走 fund provider，其他走 tencent provider。两个 API 并行请求后合并结果。
