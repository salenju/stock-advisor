模块以 `index.js` 为进程入口，加载根目录 `config.json` 后并行启动两个独立子任务：`server.js` 基于原生 `node:http` 暴露 RESTful API 并静态托管 Vite 构建产物；`scheduler.js` 通过 `setTimeout` 循环执行 `runOnce`，依据各市场时区判断交易时段并动态调整刷新间隔。

内部按职责分层、依赖单向：
- 数据层 `store.js` 维护内存缓存 + 文件 mtime 检测，串行写盘链（`writeChain` Promise 队列）避免并发覆盖，持久化到 `data/holdings.json`，并在首次加载时将旧版扁平结构迁移为多次买入记录模型。
- 行情适配层 `provider/` 抽象多数据源：`tencent.js` 批量拉取 A/港/美股实时价，`fund.js` 逐个查询东方财富基金净值 JSONP，`fx.js` 提供汇率换算；统一约定输入代码数组、输出 `{price, prevClose}` 映射。
- 策略层 `strategy.js` 对持仓聚合计算成本加权止盈/止损线与最近买入价跌幅，输出 `{trigger, advice}`。
- 通知层 `notifier.js` 构造飞书 interactive 卡片，支持 secret HMAC-SHA256 签名与 3 次重试。
- 业务路由集中在 `server.js` 的 `handleApi`，统一处理 `/api/holdings*`、`/api/import-csv`、`/api/trend`、`/api/test-feishu` 等路径。
- CSV 导入拆分为可复用的 `import-csv-core.js`（纯函数）+ CLI 脚本 `import-csv.js`，共享同一套幂等匹配与 LIFO 成本计算逻辑。
依赖方向严格单向：`index` → `server/scheduler` → `store/provider/strategy/notifier`，CSV 导入不依赖运行时状态。
