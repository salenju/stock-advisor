- 所有对外暴露的异步副作用（读盘、写盘、HTTP 请求）均返回 Promise，并通过 `.catch` 吞错或降级，保证调度循环不因单条失败中断。
- 持仓数据的派生字段（均价、市值、收益率、目标/止损价）通过独立的 `withDerived` / `syncFromPurchases` / `agg` 函数集中计算，避免在多处重复实现成本加权逻辑。
- 新增数据源通过 `provider/` 下的适配器模式接入，统一约定输入代码数组、输出 `{price, prevClose}` 映射，便于 `scheduler.js` 用 `Promise.all` 并行拉取。
- ID 生成采用 `pid()` / `h...` 前缀 + `Date.now().toString(36)` + 随机后缀的短 ID 方案，在 `server.js` 与 `import-csv-core.js` 中保持一致风格。
- CSV 导入与 HTTP 导入共用 `import-csv-core.js` 中的纯函数，CLI 与 API 仅负责 IO 与参数解析，业务规则不耦合传输协议。
- 飞书消息通过 `buildCard` 根据 `payload.trigger` 分支构造不同模板，调用方只关心语义化 payload，不感知卡片结构细节。
