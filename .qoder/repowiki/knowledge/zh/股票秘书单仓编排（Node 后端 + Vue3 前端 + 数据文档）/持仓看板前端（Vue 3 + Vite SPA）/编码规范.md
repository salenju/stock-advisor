- 业务状态与副作用统一封装为 composables（如 useHoldings、useTheme），通过返回对象暴露响应式状态与操作方法，组件内仅消费不直接持有状态。
- 所有 HTTP 请求集中在 useHoldings 内部，采用统一的 fetch(url, { method, headers, body }) 模式，并在非 2xx 时抛出包含后端 error 字段的错误信息。
- 写操作（添加持仓、提交交易、保存/删除买入记录、更新持仓字段）完成后统一调用 fetchHoldings() 重新拉取列表以保持数据一致性。
- 可复用枚举（投资策略、地区、持仓类型、刷新间隔）集中定义在 constants/options.js，组件与 composable 通过 import 共享，避免硬编码。
- 弹窗类交互由 App 层用 ref(false) 控制 show 状态，并以 props + close 事件向子组件传递可见性与关闭回调。
- 主题切换通过修改 document.documentElement.dataset.theme 与 classList.toggle('dark') 实现，并将选择结果持久化到 localStorage 的 theme 键。
