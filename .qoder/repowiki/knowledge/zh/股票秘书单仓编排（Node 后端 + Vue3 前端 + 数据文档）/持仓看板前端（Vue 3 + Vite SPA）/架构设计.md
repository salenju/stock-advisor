入口 index.html 挂载 #app，由 src/main.js 通过 createApp(App) 启动并引入全局样式 style.css。App.vue 作为根组件编排布局：组合 AppHeader、OverviewCards、TrendPanel、HoldingList 以及四个弹窗组件（AddHoldingModal、TransactionModal、BuyRecordModal、ImportCsvModal），集中管理弹窗可见性与表单状态，并通过 props 下发数据、emit 事件回调。业务状态与副作用统一收敛在 composables/：useHoldings.js 以模块级单例 ref 维护全局 holdings/loading/error/countdown/fxRates，并提供所有读写 /api/holdings* 的函数；useTheme.js 管理深色/浅色主题并持久化到 localStorage；useFormat.js 提供格式化逻辑。常量集中于 constants/options.js，定义投资策略、地区、持仓类型枚举及自动刷新间隔，确保前后端枚举一致。组件之间通过 props + emit 通信，无跨组件直接共享响应式变量。
