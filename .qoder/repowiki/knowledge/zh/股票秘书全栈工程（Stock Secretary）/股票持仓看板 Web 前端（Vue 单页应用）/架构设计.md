入口 `index.html` 挂载 `#app`，由 `src/main.js` 通过 `createApp(App)` 启动；`App.vue` 作为根组件编排布局，组合 `AppHeader`、`OverviewCards`、`HoldingList` 及多个弹窗组件（`AddHoldingModal`、`TransactionModal`、`BuyRecordModal`、`ImportCsvModal`）。状态与副作用集中在 `composables/`：`useHoldings.js` 以模块级单例 ref 维护全局持仓、加载态、错误与倒计时，并提供所有读写 `/api/holdings*` 的函数；`useTheme.js` 管理深色/浅色主题并持久化到 localStorage；`useFormat.js` 提供格式化逻辑。常量集中于 `constants/options.js`，定义投资策略、地区、持仓类型枚举及自动刷新间隔，确保前后端枚举一致。UI 样式使用 Tailwind CSS 与 DaisyUI 主题（`data-theme="stockdark"`），全局样式在 `style.css` 中引入。组件之间通过 props 下发数据、emit 事件回调，弹窗状态由 App 层集中管理。
