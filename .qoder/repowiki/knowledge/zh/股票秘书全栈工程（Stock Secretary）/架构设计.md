根目录作为单仓编排层，将三个子模块按职责解耦：server/ 提供 REST API 与行情调度任务，web/ 是 Vue3+Vite 前端源码，data_and_docs/ 存放持仓快照 JSON、交易 CSV 及项目文档。运行时由根 package.json 的 scripts 统一入口：`npm run dev` 启动 Vite 开发服务器（:5173），并通过 vite.config.js 中的 proxy 将 /api 请求转发到 server/index.js（:3000）；`npm start` 或 `./start.sh` 在生产模式先构建 web/ 到 dist/，再由 Node 服务直接托管静态资源，实现前后端同进程部署。config.json 是跨子模块共享的唯一配置源，server/ 读取 schedule/server/feishu/notify 字段驱动行情拉取频率、端口与飞书告警，web/ 通过 /api 间接消费同一份业务数据。start.sh 封装了 Node 版本检查、依赖安装、dev/prod 两种启动流程以及 Ctrl+C 时同时终止前后端进程的清理逻辑。
