# 股票秘书

纯静态的持仓记录 / 复盘工具：数据存在访问者自己的浏览器（或自己的 GitHub 私有仓库），实时行情由浏览器直连，**不需要任何后端进程**，构建产物可以直接扔到 GitHub Pages、Netlify、Vercel 或任意静态托管。

## 功能

- **持仓与交易**：A 股 / 港股 / 美股 + 场外基金；多次买入 / 卖出 / 分红 / 送转；手续费计入成本与盈亏
- **成本法可选**：LIFO（默认）/ FIFO / WAC 移动加权平均，可显式重算历史卖出成本
- **实时行情**：浏览器直连腾讯财经（A 股/港股/美股）与东财基金净值，交易时段自动刷新
- **策略提示**：止盈（成本加权）、止损（按笔）、补仓（降幅/目标价）、移动止盈、单日涨跌告警
- **复盘统计**：已清仓战绩、胜率、盈亏比、年度已实现收益、最佳/最差 Top3、组合分布饼图
- **每日快照**：当天首次打开且已过收盘时间时自动补记一条，供复盘与 CSV 导出
- **CSV**：导入买卖记录（幂等去重）、导出交易明细 / 归因统计 / 每日快照
- **PWA**：可安装到桌面 / 手机主屏，离线可打开界面

## 快速开始

环境：Node.js >= 18。

```bash
npm install
npm run dev        # 开发服务器 → http://localhost:5173
npm run build      # 构建到 dist/
npm run preview    # 本地预览构建产物
```

## 部署到 GitHub Pages

仓库已内置 `.github/workflows/pages.yml`：推送到 `main` / `master` 即自动构建并发布。

只需在仓库里做一次设置：

> **Settings → Pages → Source 选「GitHub Actions」**

工作流会自动注入两个构建变量，无需改代码：

| 变量 | 值 | 作用 |
| --- | --- | --- |
| `VITE_DATA_MODE` | `local` | 默认以本地数据模式启动 |
| `VITE_BASE` | `/${{ github.event.repository.name }}/` | 项目站点地址是 `https://<user>.github.io/<repo>/` |

注意：

- 用**自定义域名**时，把工作流里的 `VITE_BASE` 改成 `/`（或删掉该行）
- 仓库是公开的也没问题：**仓库里没有任何个人数据**，每个访问者的浏览器都是独立的一份空数据，第一次打开后用「🗄 数据」导入自己的备份即可
- 本地等价命令：

```bash
VITE_DATA_MODE=local VITE_BASE=/<你的仓库名>/ npm run build
npm run check:pages   # 模拟 /<repo>/ 子路径部署并校验资源 404 / manifest / 可安装 / SW 作用域
```

## 数据放在哪：两种模式

页面顶部会显示当前模式，点「**🗄 数据**」可随时切换（切换会整页刷新；两种模式共用同一份本机数据，切换不删数据）。

| 模式 | 数据位置 | 能力 |
| --- | --- | --- |
| **本地数据**（`🔒`） | 只在这台设备的浏览器（IndexedDB），不经过任何服务器 | 持仓 / 交易 / 复盘统计 / CSV / **实时行情（浏览器直连腾讯·东财）** / JSON 备份导出导入 / 自动版本快照回滚 |
| **GitHub 私有仓库**（`☁️`） | 本机 IndexedDB + 你**自己的私有仓库**里的一个文件，跨设备自动同步，可选端到端加密 | 本地模式的全部能力 **+ 手机和电脑共用一份数据 + 改动后自动上传 + 双向合并** |

**隐私承诺**：本地模式完全不联网存储；GitHub 模式只写进**你自己账号下的私有仓库**，别人看不到。行情请求直连腾讯/东财，持仓数据不会发送给它们。

三种进入/切换方式（优先级从高到低）：

```bash
# 1. 网址后面加 ?mode=local 打开一次（会被记住，之后 URL 里的参数自动移除）
http://localhost:5173/?mode=local

# 2. 页面右上角「🗄 数据」→ 选择「🔒 本地数据」/「☁️ GitHub 私有仓库」

# 3. 构建期指定（GitHub Pages 用这种方式）
VITE_DATA_MODE=local npm run build
```

**从旧版后端迁移**：在旧版页面导出 `data/holdings.json`（裸数组或完整备份包均可）→ 切到本地模式 → 「🗄 数据」→ 选择该文件 → 按「合并」导入。示例文件见 `data/holdings.example.json`。

**已随后端一起移除的能力**：飞书机器人推送、无人值守定时任务、历史收益趋势图（依赖后端 K 线重放）。收益归因与每日快照仍在，用「复盘统计」页查看。

## 把 GitHub 私有仓库当「数据库」（跨设备同步）

不想开服务器、又想手机和电脑共用一份数据？把数据存进**你自己账号下的私有仓库**即可。

1. **建一个私有仓库**（例如 `stock-data`，空仓库就行，不需要 README）
2. **生成细粒度令牌**：<https://github.com/settings/personal-access-tokens/new>
   - Repository access → 只选那一个仓库
   - Permissions → Contents: **Read and write**（其余保持 No access）
   - 过期时间建议 90 天，过期后换新令牌即可
3. 打开「**🗄 数据**」→ 选「**☁️ GitHub 私有仓库**」→ 依次填入 用户名 / 仓库名 / 令牌 → 点「**测试连接**」
   - 面板会显示仓库是私有还是公开、云端是否已有数据文件
   - **仓库是公开的会被拦下**：公开仓库里放持仓数据等于公开，`双向同步`/`上传` 按钮会保持禁用
4. 点「**上传到云端**」创建第一个云端文件；之后每次**持仓/交易数据**改动会自动上传（停止操作 **3 分钟**后合并推送一次）。行情刷新只写本机，不会产生云端提交
5. 在另一台设备（比如手机）打开同一个页面 → 选云同步模式 → 填**同样的四个字段** → 点「**从云端拉取**」

**加密口令（可选，强烈建议填）**：填了口令后，数据在本机用 AES-GCM（PBKDF2-SHA256，20 万次迭代）加密再上传，GitHub 上只有密文 —— 即使仓库被误设为公开、或令牌泄露，别人也读不到持仓。

> ⚠️ **口令没有找回途径**。忘记口令 = 那份云端数据解不开，只能换口令重新上传覆盖。口令请和令牌一起存进密码管理器。
> 口令不会发给 GitHub，也不存在任何服务器上，**只在这台设备的 localStorage 里**。

**令牌与口令是两件事**，故意分开：

| | 作用 | 泄露后的影响 | 怎么补救 |
| --- | --- | --- | --- |
| **访问令牌** | 让页面能读写那个仓库 | 别人能改/删仓库文件 | 去 GitHub 撤销令牌，重新生成一个 |
| **加密口令** | 本地加密，GitHub 只见密文 | 只说密文被解开（前提是**也**拿到密文） | 换口令 → 重新上传覆盖云端 |

**其他设备的更新**：页面每分钟检查一次云端。发现别的设备提交过新版本时，顶部会出现「云端有来自其他设备的更新」，点「**立即同步**」就会先拉取、按 `市场|代码` 合并，再把合并结果写回云端；点「稍后」则本次不再提醒（同一版本不会反复弹）。

**冲突怎么处理**：以上传/拉取时远端文件的 `sha` 作为乐观锁。如果另一台设备刚推过，会自动重读一次再试；若两边都改过，会提示「远程已有更新，请先『从云端拉取』合并后再上传」。合并规则与本地导入一致：按 `市场|代码` 去重，交易记录更完整的一方优先，本机多出来的持仓不会被删。

**清空注意**：云同步模式下的「清空本机数据」只清本机，云端文件不会被删除，下次拉取会把数据带回来。

**不想加密？** 口令留空即上传明文信封（仍是结构化 JSON，方便直接打开仓库文件抢救数据）。但这样就只剩「仓库私有」这一道防线。

## 备份与恢复

- 「🗄 数据」→「导出完整备份（JSON）」：持仓 + 快照 + 汇率设置，是换设备/清缓存前的唯一恢复途径
- 交易数据每次变化前自动留一份版本快照（最多 30 份），可回滚
- 超过 7 天未导出备份会提醒；清空本地数据需二次确认
- CSV 仅用于 Excel 查看，不能替代完整备份（不含汇率设置）

## 自动化测试

```bash
npm test              # node:test 单元测试（账本/策略/统计/快照/行情解析/云同步）
npm run test:sync     # 云同步纯单测（信封加密往返 / GitHub Contents API 客户端，= npm test 的子集）
npm run check:local   # 本地模式端到端（无头 Chrome：导入→行情→持久化→导出→回滚→模式面板）
npm run check:sync    # 云同步端到端（拦 GitHub API 用内存假仓库，跑通配置→上传→换设备拉取）
npm run check:pages   # 子路径部署检查（VITE_BASE=/<repo>/ 构建 + 模拟 Pages 托管 + 可安装性）
npm run check:layout  # 移动端布局度量检查
```

> `check:*` 需要本机安装 Chrome（脚本内为 macOS 默认路径）且能访问行情接口；`check:local/sync/layout` 读取 `dist/`，先 `npm run build`。

## 技术栈

- 前端：Vue 3 + Vite + TailwindCSS + daisyUI + ECharts
- 存储：IndexedDB（降级 localStorage）
- 行情：腾讯财经（免 Key，浏览器直连）+ 东方财富基金净值
- 同步：GitHub Contents API + 可选 AES-GCM 端到端加密
- 测试：node:test + puppeteer-core
