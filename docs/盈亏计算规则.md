# 股票秘书 — 盈亏计算规则

> 版本：v1.0  
> 关联文档：技术设计.md、需求文档.md  
> 适用范围：持仓盈亏、成本均价、交易记录的所有数值派生

---

## 1. 交易模型

每只持仓（Holding）维护两个独立的记录数组：

```
Holding
├── purchases[]   // 买入记录（一条或多条）
└── sells[]       // 卖出记录（可空）
```

**关键原则**：卖出不修改任何买入记录；所有买入记录永久保留。

### 1.1 买入记录 `Purchase`

```ts
interface Purchase {
  id: string;
  buyPrice: number;           // 买入单价
  buyQuantity: number;        // 买入数量
  buyTime: string;            // 买入日期 (YYYY-MM-DD)
  targetProfitRate: number;   // 本笔的止盈收益率 (%)
  stopLossRate: number;       // 本笔的止损收益率 (%)
}
```

### 1.2 卖出记录 `Sell`

```ts
interface Sell {
  id: string;
  sellPrice: number;          // 卖出单价
  sellQuantity: number;       // 卖出数量
  sellDate: string;           // 卖出日期 (YYYY-MM-DD)
  costPrice: number;          // 卖出时的成本均价（LIFO 计算，见 §2.2）
  profit: number;             // 该笔卖出实现的盈亏金额
  returnRate: number;         // 该笔卖出实现的收益率(%)
}
```

## 2. 成本计算

### 2.1 总买入

```
总买入成本   = Σ(purchases[].buyPrice × purchases[].buyQuantity)
总买入数量   = Σ(purchases[].buyQuantity)
```

### 2.2 卖出成本（LIFO）

每次卖出时，按 **后进先出（LIFO）** 从最新买入记录开始匹配，计算卖出部分的成本均价：

```
sortedPurchases = purchases 按 buyTime 降序

remaining = sellQuantity
totalCost = 0
for each p in sortedPurchases:
    take = min(remaining, p.buyQuantity)
    totalCost += take × p.buyPrice
    remaining -= take
    if remaining <= 0 → break

if remaining > 0 → ❌ 卖出数量超过持仓数量，报错

costPrice = totalCost / sellQuantity
```

**公式**：`costPrice = (最新 N 笔买入按 LIFO 匹配出的成本之和) / sellQuantity`

### 2.3 剩余仓位

```
已卖出成本   = Σ(sells[].costPrice × sells[].sellQuantity)
已卖出数量   = Σ(sells[].sellQuantity)

剩余成本     = max(总买入成本 − 已卖出成本, 0)
剩余数量     = max(总买入数量 − 已卖出数量, 0)
剩余均价     = 剩余数量 > 0 ? 剩余成本 / 剩余数量 : 0
```

> 剩余成本/数量/均价实时反映当前手上还有多少仓位、成本是多少。

## 3. 盈亏计算

### 3.1 单笔卖出盈亏（实时存储，无需二次计算）

```
卖出利润     = (sellPrice − costPrice) × sellQuantity
卖出收益率   = costPrice > 0 ? (sellPrice − costPrice) / costPrice × 100 : 0
```

写入 `sells[].profit` 和 `sells[].returnRate`，用于后续汇总。

### 3.2 汇总指标

#### 当前市值

```
市值 = currentPrice × 剩余数量
```

#### 未实现盈亏（浮动盈亏）

```
未实现盈亏 = (currentPrice − 剩余均价) × 剩余数量
```

#### 已实现盈亏（已卖出部分）

```
已实现盈亏 = Σ(sells[].profit)
```

#### 持仓总盈亏

```
持仓盈亏   = 未实现盈亏 + 已实现盈亏
持仓收益率 = 总买入成本 > 0 ? 持仓盈亏 / 总买入成本 × 100 : null
```

> 分母用「总买入成本」而非「剩余成本」，因为总买入成本才是该持仓的全部投入。

#### 今日盈亏

```
今日盈亏   = (currentPrice − prevClose) × 剩余数量
今日收益率 = prevClose > 0 ? (currentPrice − prevClose) / prevClose × 100 : null
```

> 仅用「剩余数量」而非「全部买入数量」，已卖出的部分不再产生当日浮动盈亏。

## 4. 交易流水展示

### 4.1 合并排序

买入记录和卖出记录合并为一条时间线，按日期倒序排列：

```
transactions = [
  { ...purchase, type: 'BUY'  },
  { ...sell,    type: 'SELL' },
].sort(by buyTime DESC)
```

### 4.2 字段覆盖规则

| 字段 | 买入 (type=BUY) | 卖出 (type=SELL) |
| --- | --- | --- |
| 日期 | `buyTime` | `sellDate` |
| 价格 | `buyPrice`（买入价） | `sellPrice`（卖出价） |
| 数量 | `buyQuantity` | `sellQuantity` |
| 成本 | `buyPrice × buyQuantity` | `costPrice × sellQuantity` |
| 市值/成交额 | `currentPrice × buyQuantity` | `sellPrice × sellQuantity` |
| **收益/收益率** | **`-- / --`** | **`profit / returnRate`** |
| 止盈% | `targetProfitRate` | `—` |
| 止损% | `stopLossRate` | `—` |
| 操作 | 修改 / 删除 | 无 |

> 买入记录不展示收益——未卖出的份额仅体现在汇总层面的「未实现盈亏」中。

---

## 5. 汇总卡展示

| 指标 | 公式 | 说明 |
| --- | --- | --- |
| 市值 / 数量 | `市值 = currentPrice × 剩余数量` / `数量 = 剩余数量` | |
| 成本 / 现价 | `成本 = 剩余成本` / `现价 = currentPrice` | |
| 今日收益/收益率 | `(现价−昨收) × 剩余数量` / `(现价−昨收)÷昨收×100` | 仅未卖出份额 |
| 持仓收益/收益率 | `未实现+已实现` / `总盈亏÷总买入成本×100` | |
| 止盈% / 止损% | 买入记录成本加权均值 | 不随卖出变化 |

## 6. 数据流

```
用户操作
  │
  ├─ 添加买入记录 (POST /purchases)
  │   └─ push → purchases[]
  │
  ├─ 修改买入记录 (PATCH /purchases/:id)
  │   └─ 更新 purchases[] 中的单价/数量/日期/止盈/止损
  │
  ├─ 删除买入记录 (DELETE /purchases/:id)
  │   └─ 从 purchases[] 移除
  │
  ├─ 卖出 (POST /transactions, type=SELL)
  │   ├─ LIFO 计算 costPrice
  │   ├─ push sell → sells[]
  │   └─ 不修改 purchases[]
  │
  └─ 买入 (POST /transactions, type=BUY)
      └─ push → purchases[]

后台定时刷新行情
  ├─ 更新 currentPrice / prevClose
  └─ syncFromPurchases() → 重新计算剩余成本/数量/均价（持久化）

页面请求 GET /api/holdings
  └─ withDerived() → 返回 transactions + 所有汇总指标（运行时计算）
```


```
剩余数量     = 总买入数量 − 总卖出数量
剩余成本     = 总买入成本 − Σ(每单 sell.costPrice × sellQuantity)
剩余均价     = 剩余成本 / 剩余数量
剩余市值     = 当前价 × 剩余数量
未实现盈利   = (当前价 − 剩余均价) × 剩余数量
持仓总收益   = 未实现盈利 + 已实现盈利(Σ sells.profit)
```
