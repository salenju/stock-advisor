# 自测清单（功能上线检查）

> 配套功能：① 按币种拆分 + 汇率换算人民币；② 收益趋势看板（echarts）；③ 自动化测试。
> 执行 `npm test` 运行自动化测试（28 项，全部通过）。

## 二、手动 UI 检查清单

### 功能 1：币种拆分 + 汇率换算
- [ ] 概览四张卡片（总成本/总市值/今日收益/持仓收益）显示**折合人民币**金额
- [ ] 每张金额卡片右上角有 ⓘ 图标，点击弹出**按币种小结**：
