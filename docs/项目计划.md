# 股票秘书 — 项目计划

> 版本：v1.0
> 关联文档：需求文档.md、技术设计.md

---

## 1. 目标与范围

在 v1.0 内交付一个可稳定运行的个人股票秘书：

- 维护多市场持仓数据（港股 / 美股 / A股）
- 定时抓取实时行情
- 基于阈值判断买点 / 卖点
- 通过飞书机器人推送结构化提醒

---

## 2. 里程碑

| 阶段 | 名称 | 交付物 | 预计周期 |
| --- | --- | --- | --- |
| M1 | 数据与配置骨架 | 持仓数据模型、配置文件、示例数据 | 第 1 周 |

## 3. 任务拆解

### M1 数据与配置骨架
- [ ] 定义持仓记录数据结构（字段、枚举、类型）
- [ ] 设计配置文件（行情源、飞书 Webhook、刷新频率、默认阈值）
- [ ] 编写示例持仓数据（覆盖股票 / 基金 / ETF、三市场）

### M2 行情抓取模块
- [ ] 抽象行情接口 `PriceProvider`
- [ ] 实现 A股 行情适配器
- [ ] 实现 港股 行情适配器
- [ ] 实现 美股 行情适配器
- [ ] 定时刷新调度 + 失败重试 / 降级
- [ ] 行情缓存与「最近更新时间」

### M3 策略判断引擎
- [ ] 收益率 / 跌幅计算（相对成本、相对最近买入价）
- [ ] 卖点（止盈）判断逻辑
- [ ] 买点（补仓）判断逻辑
- [ ] 触发状态机（未触发 → 触发 → 已提醒 → 复位）
- [ ] 去重与冷却机制（避免刷屏）

### M4 飞书推送
- [ ] 飞书自定义机器人 Webhook 封装
- [ ] 消息模板（买点 / 卖点 / 概览）
- [ ] 推送失败重试与日志

### M5 集成与运维
- [ ] 主调度循环串联：抓取 → 判断 → 推送
- [ ] 统一日志（抓取 / 判断 / 推送）
- [ ] 启动脚本 + 定时任务（cron / systemd / 云函数）

### M6 验收与调优
- [ ] 按需求文档验收标准逐条联调
- [ ] 校准阈值参数、冷却时长
- [ ] 编写运行说明（README 补充）

---

## 5. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 第三方行情 API 不稳定 / 限流 | 抓取失败 | 多源降级、重试、缓存上次成功价 |
| 美股 / 港股 行情需特殊权限或付费 | 部分市场无数据 | 优先免费源，付费源作为可插拔选项 |
| 飞书 Webhook 频率限制 | 提醒丢失 | 收敛消息、合并推送、冷却 |
| 时区差异（美股盘后） | 误判触发 | 按市场本地交易时段判断活跃度 |

---

## 6. 验收口径

以需求文档第 6 节「验收标准」为准，逐条核对：
1. 持仓字段可录入 / 编辑
2. 三市场实时价格可获取并对照
3. 飞书提醒及时、结构化
4. 提醒不去重刷屏
5. 配置可外部调整
